Apple Music's feel. YouTube Music's catalogue.

AppleTube is a native SwiftUI app. Everything you see is built natively, and the music is played by YouTube Music's own player, so Premium works as it does on the web: no ads, background play, your quality settings.

🎤

Synced lyrics

Lines scroll and light up in time, tap a line to jump, animated dots in instrumental breaks. Uses YouTube's timed lyrics, then LRCLIB.

📜

A real queue

History, Continue Playing, swipe to remove, Shuffle, Repeat and Autoplay. Play Next or Play Last works on songs, albums and playlists.

🎨

Designed playlist covers

Every playlist you own gets a cover from one design system: 12 palettes × 4 motifs, editable per playlist.

👆

Menus and swipes everywhere

Long-press any song for a preview and a full Apple Music–style menu. Swipe to queue. Add to playlists, love, create stations.

⚡️

Instant screens

Pages paint from an on-disk cache straight away, then refresh quietly. Artwork is cached and prefetched.

🔒

Lock Screen and background

Plays in the background with Lock Screen controls, artwork and AirPlay. It keeps playing when the phone locks.

🏠

Make it yours

Reorder or hide Home shelves and Library categories, pick an accent colour and theme, set a profile photo.

🌈

Pages tinted by artwork

Album and playlist pages, and Now Playing, take their colours from the artwork, as in iOS 26.

How it works

There is no backend and there are no API keys. The app talks to music.youtube.com exactly as your browser does.

Sign in

On Google's own page

You sign in inside a web view. AppleTube never sees your password; it reuses the session's cookies to sign requests.

Data

InnerTube API

Home, search, library and playlists come from YouTube Music's web API, parsed with code adapted from Kaset (MIT).

Playback

A hidden web player

YouTube Music's own player runs out of sight. The app drives it from Swift: switching tracks, editing the queue, Media Session controls.

Install it on your iPhone

It isn't on the App Store. You build it with Xcode and install it on your own phone. A free Apple ID is enough.

# needs a Mac with Xcode 26+, an iPhone on iOS 26+, and YouTube Music Premium
brew install xcodegen
git clone https://github.com/PiratedVirus/AppleTube.git && cd AppleTube
cp Local.example.yml Local.yml   # your team ID + a unique bundle ID
xcodegen generate
open AppleTube.xcodeproj         # choose your iPhone, press Run

Apps signed with a free Apple ID stop opening after 7 days. The repo includes a launch agent that rebuilds the app and reinstalls it over Wi-Fi before that happens. See the README.
